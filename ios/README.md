# iOS

SwiftUI app for Catalog. **Xcode project not created yet.**

Planned targets:
- **Catalog**: the main app (browse and search saved posts).
- **CatalogShareExtension**: the Share Extension that receives links shared from Instagram, TikTok, etc.
  Shares data with the main app through an App Group.

API client code is generated from [`../api/openapi.yaml`](../api/openapi.yaml),
for example with Apple's `swift-openapi-generator`. Generated code is not committed.
